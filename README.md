# Caesar Cipher

## What it does
Encrypts and decrypts text using the Caesar Cipher algorithm. Also includes
a brute-force option that tries all 25 possible shifts.

## How to run
```
python caesar_cipher.py
```
No extra dependencies needed — pure Python 3.

## Features
- Encrypt with any shift (1–25)
- Decrypt with known shift
- Brute-force all 25 shifts
- Preserves spaces, numbers, and special characters
- Case-sensitive (uppercase stays uppercase)

## Example
```
Message : Hello World
Shift   : 3
Encrypted: Khoor Zruog
```
